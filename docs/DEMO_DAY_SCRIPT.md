# Ilova — Q&A tayyorgarligi (juryning ehtimoliy savollari)

**"Mango allaqachon bor-ku, farqingiz nima?"**
→ "Mango — Carrot kloni, faqat savdo. Bizda savdo + gaz/mahalla ma'lumoti. Ular past chastotali, biz — har kunlik. Va bizda ularda yo'q qatlam bor."

**"Gaz ma'lumotini kim kiritadi?"**
→ "Ikki manba: mahalla raisi (rasmiy, tasdiqlangan belgi bilan) va aholi o'zi ('oldim/kelmadi'). Hatto bitta odam 'hozir qayerdaman'ni yangilasa — muammoning 80%i hal bo'ladi."

**"Daromad modelingiz isbotlanganmi?"**
→ "Mahalliy biznes reklamasi — Bir Bir'da 'PRO' allaqachon ishlaydi. Biz uni hyperlokal va mahalla auditoriyasi bilan kuchaytiramiz."

**"Nega backend hali to'liq emas?"**
→ "Frontend to'liq tayyor, backend kontraktlari yozilgan. Inkubatsiya davomida to'liq ishga tushamiz — grant aynan shunga."

**"Miqyoslash qanday?"**
→ "Har mahalla — mustaqil birlik. Bittadan boshlab, shablon bilan kengaytiramiz. Zichlik lokal — bitta mahallada kritik massa yetadi."
